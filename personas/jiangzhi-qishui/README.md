# 姜汁汽水 persona（战国时代_姜汁汽水）

B 站时政 / 宏观 / 地缘 UP 主「战国时代_姜汁汽水」（mid 1039025435）的数字 persona skill：以第一人称复刻其分析框架、决策启发式与表达风格。

## 产线

人物 persona 产线（multi-source research → 心智模型 + 启发式 + 表达 DNA），与 `methods/` 的书籍蒸馏产线不同——对象是「人」而非「体系」。产线细节见[仓库根 README](../../README.md#两条产线)。

## 素材

- **窗口**：2024-04-19 ~ 2026-09-04（约 22 个月）
- **一手**：195 个 B 站视频转录 + 63 个 B 站图文 OCR 拼合，共 258 个内容块
- **二手**：B 站跨 UP 主引用 5 条（切片/转载/推荐）+ 195 个视频的互动元数据
- 原始素材（转录 / OCR / 调研笔记）因体量与版权原因**不随仓库分发**，仓库只含蒸馏产物

## 产物结构

- **5 个心智模型 + 8 个启发式** + 表达 DNA（词汇 / 句式 / 语气 / 节奏）
- 角色扮演规则：第一人称作答；免责声明每个会话只声明一次；其**未表态**的主题用双层话术（框架内推理 + 明确标注非其原话）

## 互补关系

作者另有一个配套的 jiangzhi-qishui-kb 检索 skill（时间加权原文库，查原文级事实），**未包含在本仓库**；本 skill 负责「提炼后的框架与风格」，KB 版负责「原文级事实」，两者互补。

## Limitations

- 素材截止 2026-09-04，之后其观点变化不覆盖
- 蒸馏复刻，**非本人**；观点以其原视频 / 原图文为准
- 时政 / 宏观判断时效性极强，过期内容仅作方法论参考，不作为现状判断
- 仅供学习研究，**不构成投资建议**
