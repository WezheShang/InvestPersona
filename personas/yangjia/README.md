### 自建数据库最小化示例

把 1 万只 A 股日 K 落本地 CSV，2GB 空间够用 5+ 年：

```python
# save_a_kline.py —— 拉全市场 8 年日 K 落本地（示意，需 Tushare 2000+ 积分）
import tushare as ts
import pandas as pd
from pathlib import Path

ts.set_token('YOUR_TUSHARE_TOKEN')  # 注册 https://tushare.pro
pro = ts.pro_api()

# 1. 拿全市场股票代码
stock_list = pro.stock_basic(list_status='L', fields='ts_code,name').values.tolist()

# 2. 拉每只日 K（用 fund_daily 拉 ETF，普通股票用 daily）
Path('data/kline_daily').mkdir(parents=True, exist_ok=True)
for ts_code, name in stock_list:
    try:
        if ts_code.endswith('.SH') or ts_code.endswith('.SZ'):
            # ETF 走 fund_daily
            if name.endswith('ETF') or 'ETF' in name:
                df = pro.fund_daily(ts_code=ts_code, start_date='20180101', end_date='20260828')
            else:
                df = pro.daily(ts_code=ts_code, start_date='20180101', end_date='20260828')
        df.to_csv(f'data/kline_daily/{ts_code.replace(".","_")}.csv', index=False)
    except Exception as e:
        print(f'{ts_code}: {e}')
```

> ⚠️ **数据合规性自检**：A 股数据商用需注意数据源授权（Tushare 个人研究 OK，akshare 部分端点限制商用）。本项目**不**承担因数据源合规问题产生的法律责任。

## 🎯 使用示例（demo）

### Use case: "分析一下 9/8 日的 A 股情绪吧"

**给数字人的 prompt**：
```
"分析一下 9/8 日的 A 股情绪吧"
```

**数字人会按 6 心模 + 情绪周期 4 阶段框架给你解读**（示意输出）：

> 我以养家视角和你聊，基于公开言论提炼，非本人观点。
>
> **1）本地素材扫描**：
> A 股情绪周期 / 当日数据：本地素材**零命中**（OCR 最后可证实的操盘动作是 2021-05-24 华银电力集合竞价）—— 下面推演都是**框架推断，非本人立场**。
>
> **2）9/8 情绪阶段推断（用心模 1"判断为末，应变为本"+ 心模 5"散户就是最大主力" + 心模 6"变是不变"）**：
> - **冰点入场** = 左侧赌修复（赢在便宜，输在底深）—— 涨停家数极低 + 高度断档 + 炸板率极高时
> - **分歧入场** = 中继赌分歧转一致（赢在换手充分）—— 涨停/跌停同现 + 高度被压
> - **修复确认入场** = 右侧赌延续（赢在胜率高，代价是让头段利润）—— 龙头收复失地 + 量能恢复
> - **高潮入场** = 赌不接最后一棒（赢面最差，所有人看多时市场没买盘了）—— 涨停极高 + 一字板 + 全民吹票
>
> 9/8 这种"用户主动问当日情绪"的场景，按我的原则是**不预测大盘点位** [OCR p.13]，准备 3 个 regime 的预案（这 3 段引自我的清华演讲 [§五 时间架构]），不预先归类。
>
> **3）给你做判断的仪表盘**（请自己拉数据喂给数字人）—— 需要你提供：
> - 当日涨停/跌停/炸板率/最高连板（财联社 `x-quote.cls.cn` 或东财 push2）
> - 上证/创业板/科创板成交额 + 涨跌家数
> - 主流板块 5 个 + 各自龙头
> - 你的自选股 / 持仓表现
>
> **4）我**不会**给的操作建议**：
> - ❌ "9/8 适合加仓 159516"
> - ❌ "龙头是 X，今天追板"
> - ❌ "主力会怎么走"
>
> 我**只**给"养家方法论会怎么解读 9/8 的盘面特征"，具体决策**由你**拍板。

### 数字人**不会**做的事

- ❌ 给你**具体股票代码**（"养家会买 X"）
- ❌ 给你**买卖点位 / 止损位**（"X 涨到 Y 卖"）
- ❌ **预测大盘点位**（"9/8 收 3800"）
- ❌ **编造养家原话**（任何引用必带 [OCR p.X] / [清华演讲 §X] 出处）
- ❌ 把"框架推断"包装成"养家本人立场"

## 🧠 6 个核心心智模型（速览）

> 完整版本（含证据 + 应用 + 局限）在 `SKILL.md`

1. **判断为末，应变为本** —— 市场最大的确定性就是不确定
2. **看好买入，不看好卖出** —— 止盈止损是机械束缚
3. **弱水三千只取一瓢 / 能赚 1 块只赚 7 毛** —— 留 3 毛济世
4. **稳定的心态是短线操作的前提** —— 事理通达心气和平
5. **散户就是最大主力 / 龙头是散户共识载体** —— 散户情绪所在，就是人气所在
6. **变是不变 → 方法论自迭代** —— 理论只能领先市场 10-20 年

## ⚠️ 已知限制

- **时效性**：本地素材截止 **2021-05-24**（OCR 最后一条具体操盘动作）+ **2019-11**（清华演讲）。**2022-2026 养家公开发言空白**。
- **数据丰度**：仅 202 页 OCR + 4500 字演讲。**没有**养家每日复盘原文、**没有**完整交易记录。
- **二手转述误差**：养家心法 PDF 是网友"菩萨戒子"整理（养家未亲笔出书），清华演讲是用户整理转录——**两层二手**误差。
- **剔除的旧版数字**：v1-network 旧版含 1971 出生 / 1997 开户 5 万 / 2013 破亿 / 2026 资金 40-50 亿 等数字**本地素材无证据**——**不要使用**。
- **沉默主题**：AI 板块 / 北交所 / 微盘股 / 可转债 / 量化态度 / 2024-09-24 政策 / 妖股 / 抱团 / 注册制 等**本地 0 命中**——数字人会标"框架推断非本人立场"。

## 🔧 二次开发

### 如何重新提炼（6 维人物提炼框架）

按以下 5 步：

1. **Phase 0.5**：建目录
2. **Phase 1**：6 维并行调研（著作 / 对话 / 表达 / 他评 / 决策 / 时间线）
3. **Phase 2**：父 session 二次提炼（三重验证：跨域复现 / 生成力 / 排他性）
4. **Phase 3**：按 SKILL.md 模板写新 SKILL.md
5. **Phase 4**：独立子 agent 做 Sanity / Edge / Voice 验证

### 如何添加新心模

在 `SKILL.md` 的"核心心智模型"段加，**必须**附三重验证：
- **跨域复现**：在 ≥ 2 个不同场景出现
- **生成力**：能推断养家对未表态问题的立场
- **排他性**：不是所有短线游资都这么说
