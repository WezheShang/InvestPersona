## §2 头肩顶（Ch6，p87-110）

**结构 4 必备阶段**：
1. A 左肩：涨势高点，量增
2. B 头：更高顶，量可平可缩（左肩 vs 头部量能差 1/3 以内都算正常）
3. C 右肩：量明显缩，顶低于头
4. D 破颈线：收盘穿透颈线 3% 才算有效

**关键规则**：
- 右肩低量成形时，头肩顶已成立 **75%**——不必等破颈线才警觉
- 约 **20% 的右肩不破颈线**（右肩升破头部 = 形态失败，概率约 1/5）
- **不完整头肩几乎不出现在长涨势早期**——上涨初期出现类似结构多数不是头肩顶；反之，长涨后期出现不完整头肩，本身就是警示
- 突破后常缩量数日再拉回颈线（「回光返照」），极少有效升回颈线上方；是否拉回看大盘环境
- **下倾颈线 = 极弱**信号（比水平颈线更凶）

**测算公式**：
- 目标 = 颈线突破点 −（头顶到颈线的垂直距离）
- 取 min（测算值，前期涨幅）——目标不应超过前期涨幅的量级

**A股适配**：涨跌停板会截断颈线突破日的 3% 确认（一字跌停无法量能确认），次日补确认；破颈线当日跌停封死时按「收盘价已达 3% 且封死」处理。

## §3 头肩底 / 复合头肩 / 圆形（Ch7，p110-139）

**头肩底与头肩顶的根本区别 = 量能**：
- **跌不需要量，涨必须量**——颈线向上突破必须放量，否则疑假突破
- 头肩底普遍更长、更平、更磨——周线图最适合

**复合头肩**（双头/双肩/多重组）：
- 颈线几乎水平，常有内外两条颈线（**只有外颈线破位有效**）
- 对称性比简单头肩更强
- 首次突破常达不到最小目标，但长线反转最终大幅超越——**中途常在最小目标位回踩**后再走主升

**圆底（碗形）**：
- 多见低价股；碗底量极度萎缩才可信（无量阴跌到底）
- 不成熟跳涨（1-2 天脉冲）常见，勿追
- 圆顶少见（高价股/优先股），量大且无规律

**休眠底**：极端大平底，月级别横盘，主力吸筹特征。

**测算**：圆形无测算公式，效力看前期跌幅 + 时间跨度（越大越强）。

## §4 三角形（Ch8，p139-174）

**对称三角**：
- 至少 **4 个反转点**（2 高 + 2 低）才能画两条边
- **效力区间 = 从起点到顶点的 1/2 - 3/4 处；超过 3/4 未突破 = 形态效力丧失**（顶点后的突破不再有三角效力）
- 约 **3/4 的对称三角是整固**而非反转
- 假突破在所有形态中最常见，但仍有 2/3 不出假突破
- 初期成交量大 + 向下突破的对称三角多为假（缺口突破 → 2-3 天震仓 → 反转走真方向）
- 突破确认：收盘超边界 3% + 量（**向上突破必须放量，向下不必**）
- 顶点本身（两条边交汇处）= 强支撑/阻力
- 测算：**从左角（第一个反转点）画平行于对边的趋势线**，价格沿此线走

**直角三角**：
- 上升三角（水平上界 + 上倾下界）→ 向上预示强、假突破少
- 下降三角（水平下界 + 下倾上界）→ 向下预示强
- 背后机制：上升三角 = 固定价位出货盘被逐渐消化；下降三角 = 固定价位收购单被吃完 → 下跌
- 整数位（40/50/75/100）常是水平边来源 = 心理抛盘位

**变体与警示**：
- 第 3/4 次调整破下界但止于前低 → 按箱体处理（不是三角失败）
- **个股走熊形态 + 指数新高 = 大熊市边缘警告**（prism 多标的横向扫描时必查）
- 周线三角可靠；月线三角松散无意义

## §5 箱体 / 双顶双底 / 三顶三底（Ch9，p174-198）

**箱体**：
- 成因 = 实力相当的两方交锋（多空拉锯），构筑期量萎缩
- 假突破远少于对称三角（可靠度接近头肩）；突破后 3 天 - 3 周拉回概率约 40%
- **整固：反转 ≈ 3:1**；反转箱体多见于底部
- **测算公式（可靠）= 箱体高度**（从突破点垂直投射）

**双顶（真形罕见，多数「双顶」是箱体）**：
- 疑似条件：两顶相隔 **1 个月以上**（间隔比跌幅更重要）+ 谷底回调 15-20% + 第 2 波量小 + 谷间走势圆形清淡
- **确认 = 有效击穿谷底**；确认后常是长线效力（非短线形态）
- 第 2 顶常略高于第 1 顶（3% 容差内算等高）
- 确认后至少再跌一个「顶到谷的距离」
- 双底第 2 底 = 缩量圆形；反弹**放量**突破两底间高点，二次探底才算成功
- 三顶三底极罕见——多数 3 高点结构按箱体处理
- 周线图看双/三顶/底更清楚

## §6 扩散 / 钻石 / 楔形 / 单日反转与抛售高峰（Ch10，p198-238）

**扩散形态（喇叭口）**：
- **90% 是熊市信号**：散户亢奋无主力控盘的标志，量全程高位且无规律，只出现在长牛最后阶段
- 标准扩散顶 = 3 个升高高点 + 2 个降低低点；**跌破第 2 低点 = 确认**
- 确认后 80% 概率有反弹（跌幅的 1/2 至 2/3），那是逃命波不是反转
- **扩散底不存在**（其环境只出现在牛市末期）——底部出现喇叭结构按别的形态重新解读

**钻石（菱形）**：
- V 形颈线的复杂头肩，或「扩散 + 对称三角」拼接；后半必须收缩 + 量缩，否则按复杂头肩处理
- 基本不出现在底部
- 测算 = 顶部至 V 形颈线交点的距离

**楔形**：
- 上升楔形 = 越走越弱（涨幅递减、买盘渐耗尽）；需 **3 周以上**（更短 = 三角旗）；跌破后回吐全部楔形涨幅甚至更多
- **上升楔形是熊市反弹中最常见的形态**——反弹末端出现上升楔形，准备反手
- 下降楔形向上突破后常先横盘/碟形再涨（持股待涨，勿被磨出去）
- 等差月线上长期熊市像巨大下降楔形 = 数学假象，必须用半对数坐标

**单日反转 / 抛售高峰 / 长钉**：
- 单日反转：量极高 + 盘中变幅 2-3% + 收盘回到前收附近——只表**短线动能枯竭**，不表反转
- **抛售高峰日（selling climax）**：强平链条终结、筹码弱手转强手；可能跨 2 天；**一般不出现在熊市最后阶段**（最后阶段的下跌是阴跌不是抛售）；抄底须快进快出
- 长钉/逃逸日：振幅 2-3 倍于常态
- 关键反转日：盘中新高、收盘落回前收之下
- **通用失效规则：价格回到形态起点 = 形态失效，立即反向**（尤其逃逸缺口、长钉类）

## §7 整固形态：旗形 / 箱体 / 头肩整固 / 连续圆底（Ch11，p238-264）

**旗形（含三角旗）**：
- 急涨（旗杆）后的小平行四边形，旗面 3 周内，**量持续萎缩**，突破后复制旗杆涨幅
- **可靠性 3 条**：①竖直走势之后 ②构筑期量显著萎缩 ③4 周内原方向突破——量不萎缩 = 短期反转区域，不是整固
- 测算 = 旗杆长（起点 = 前一形态的突破点）
- **旗形多在牛市末期**——旗形频出 = 涨势可能只剩几周；熊市第二阶段的旗形只持续 3-4 天

**其他整固**：
- 箱体整固多在牛市初期（与反转箱体多在底部对照）
- 头肩整固：涨势中形似头肩底 / 跌势中形似头肩顶，**量能规则与反转头肩相反（左肩→头→右肩量持续下降）**，头肩测算公式不适用
- 连续圆底：低价股长牛启动形态——每碗净涨 10-15%，碗间回调 20-30%，每碗 5-7 周；股价超过 15-20 美元（A股类比：脱离低价区间）后此模式消失

## §8 缺口理论（Ch12，p264-287）

**总原则**：
- **「缺口必须回补」是迷信**——回补概率 = 价格回到任意旧价位的概率，无特殊性
- 无意义缺口：最小变动价位 / 小盘股习惯性跳空 / 除权除息缺口（先复权再分析）

**四类缺口**：

| 类型 | 位置 | 量能 | 含义/用法 |
|---|---|---|---|
| 普通缺口 | 形态内部 | 平常 | 预测意义近零；形态内缺口越多越证明是整固 |
| 突破缺口 | 形态边界突破时 | 常放量 | **假突破很少带缺口**；带缺口 = 动能更强；缺口后量缩 → 50% 概率回补；量增 → 短期不回补 |
| 逃逸/测量缺口 | 趋势中段 | 适中 | **起点到缺口 ≈ 缺口到终点**（半对数最有效）；**测量规则用于离场而非入场**；多个缺口时中点缺口在中间，越后的缺口越接近衰竭 |
| 衰竭缺口 | 趋势末端 | 天量但价不延续 | 次日常单日反转收在缺口边；**前期已到测算目标 → 更可能衰竭**；衰竭前几乎总有逃逸缺口；**2-5 天内回补**；本身不是反转信号 = 叫停趋势，之后走形态再定方向 |

**岛形**：衰竭缺口 + 窄幅停滞 + 反向突破缺口（两侧缺口价位相近）。本身不是长线反转，但预示**完全回吐**该段行情；常是更大形态的内部结构。

**指数特点**：指数缺口少、且基本无衰竭缺口（纳指例外）。

**A股适配**：A股跳空远多于美股（集合竞价制度），普通缺口更常见 → 分类定级时更依赖「位置 + 量能」而非「有缺口」本身；向上突破缺口 + 涨停 → 按「带缺口的强突破」处理。

## §9 支撑与阻力（Ch13，p287-311）

**定义与机制**：
- 支撑 = 买盘（实际成交 + 潜在挂单）；阻力 = 卖盘
- 心理机制 = 套牢盘回本卖 + 获利盘回调买回
- **聪明资金在到达阻力前就涌出**——牛市二段回调只轻触支撑区上沿即反弹（回调不深 = 强）

**角色互换原则**：前高被有效突破 → 变支撑；前低被有效跌破 → 变阻力。

**S/R 强弱 3 标准**：
1. **换手量**：单个深幅天量低点 > 多个均衡量低点（天量 = 充分换手 = 强记忆）
2. **价格落差**：中低价股 10% 法则（±10% 内算一个区）；超低价股不适用
3. **时间**：越久远越弱，但例外——**从未拆分/未大量换手的股，久远价位记忆反而极强**

**操作规则**：
- 被攻过一次的阻力已部分消耗；**第三次上攻成功概率大**
- 高估阻力比低估安全（把阻力区画宽不画窄）
- 阻力区中心 ≈ 底部区间的每日收盘均值
- **周线图最理想**（能覆盖前一轮完整牛熊的 S/R）
- **突破前顶比突破整段阻力区容易**——前高只使涨势停顿，大成交量的前底才造成整固
- 整数关口 20/30/50/75/100（A股：10/20/50/100 元及整数关口）——新高遇整数必遇阻力，大盘蓝筹相对免疫
- **形态界线（颈线/三角边/箱体边）被有效突破后立即升级为强 S/R，不受 10% 规则限制**
- 对称三角的支点（顶点）= 轴心，最强但随时间衰减；轴线失守 → 加速下跌
- 击穿阻力位时量往往**在击穿之后**才放大（突破后追涨盘确认，不纠结突破当日的量）

**支撑失败的两种形式**：
1. 脱离支撑模式直接暴涨（不回调直接走）
2. 穿透支撑（= 趋势变化警告）
- **短线支撑破 = 中线反转第一步；中线支撑破 = 长线反转第一步**
- 头肩顶形成的第一征兆 = 头部下跌**击穿左肩高点**（不是等右肩）
- 恐慌下跌击垮所有支撑直到卖盘枯竭；恐慌底的大量换手 → 对后续涨势构成阻力

## §10 趋势线与通道（Ch14，p311-341）

**基本画法**：
- 牛市：依次抬高的回调低点连线；熊市：依次降低的反弹高点连线
- 两个反转点起画（试验线），第 3 次触及确认
- 颈线/形态界线 = 特殊趋势线；**趋势线常先于颈线破位 → 立即行动，不等头肩确认**
- 半对数坐标必要（等差坐标下长趋势必然变形）

**效力 3 标准（重要性排序）**：**触线次数 > 长度 > 角度**
- 第 3 个低点触线 = 确认；线越长越重要；越平越重要（10-50 美元股半对数坐标下中线约 30 度）

**穿透有效 3 标准**：**收盘破线 3% + 量印证 + 随后弱势反弹失败**
- 盘中破线收回 = 忽略；收盘价比盘中低点可靠

**修正规则**：
- 两点线被第 3 次小幅击穿 → 弃点 2，连点 1、点 3 重画
- 多次考验过的线被小幅击穿可不理
- **双重趋势线**：内线（精确触点）+ 外线（含毛刺）；外界线定生死
- 试验线永远不用「高点连低点」互连

**通道**：
- 反弹未达折返线（上轨）= 转弱——未达的距离 ≈ 未来跌破下轨的幅度
- 回调未回基本线（下轨）= 将破上轨
- 破线后反抽常**精确止于原线位**（原下轨变阻力）

**熊市通道与见底信号**：
- 熊市跌势通道不规则、常失效
- **但熊市最后一波跌势更规整平坦**（稳步下行 + 坡度不陡 + 数次触线 + 不破折返线）→ 最终向上破线 = 牛市信号

**扇形原则**：
- 同一顶点出发 F1/F2/F3 三条渐平的趋势线；**有效跌破第 3 条扇线 = 调整低点确立**
- 仅适用于牛市调整 / 熊市修复段的判定；用极短止损兜底

## §11 长线趋势线（Ch15，p341-366，P2 扫读）

- 长线（10 年+ 月线图）上等差 vs 半对数坐标差异巨大：投机型个股涨势加速 → 等差图呈上弯曲线，**半对数图呈直线 → 半对数信号更早更准**（破线时价格更高）
- 投资型股（通用/公用事业）半对数直线；高评级优先股等差图也减速下行。**股性不变原则**：多数股票跨牛熊复制前轮轨迹（投机→成熟→投资级 = 上弯→直线→减速演化）
- **最有用的长线牛市趋势线不始于熊市最低点，而是其后的中线低点**——起点建仓期平缓耗时，从最低点连线过于水平；中线版同规则：头肩形态的趋势线始于右肩而非头部
- 长线趋势线被穿透的判断要比中线多留余地

## §12 第一部分总结（Ch17，p387-391 核心；p391 后为 Bassetti 现代工具内容，P2）

**四类方法**（prism 五柱中本册的四大工具）：
1. 区域形态 + 成交量 → 入场/离场信号 + 目标位（整固与反转都积聚力量）
2. 趋势/趋势线 → 判断基本走向、探测转向、**避免过早获利了结**
3. 支撑/阻力 → 预示趋势放缓/终止、获利了结/换股信号
4. 大盘环境/道氏理论 → **不随大盘而动的股票极罕见**

**量能总纲**：
- 量是**相对**概念（牛市顶部量 > 熊市底部量；个股的「放量」对标的自身而言）
- 量追随趋势：涨放量、回调缩量；熊市中反弹也小幅放量（**涨需要买盘推动，跌像自由落体**）
- 明显放量 = 趋势的开始或结束（或主力震仓，少见）；量必须配价解读

**交易哲学**：
- 成功秘诀不在买最低卖最高，而在**避免大额损失**；巴鲁克：职业生涯从没在底部 10% 内买到、顶部 10% 内卖出
- 技术分析不要求一直持仓——有时数月离场观望是最好策略；耐心是美德
- 股价越创新高越谨慎；跌至新低时买入往往带来好结果（长线牛熊交替规律）
- 图表不完美、不是机器人；**警惕一切机械系统**（企图用纯机械方式解决非机械问题）

## §13 战术篇

### 13.1 基准点法总览（Ch5，p74-87）

- **定位**：道氏理论的工程化替代。周线版回测 1900 年以来道指：交易次数更少（25 vs 37 次）、空仓时间 ~35%（超 1/3 时间无风险）、变体 2 利润显著更高（$881K vs $537K）
- 分形市场观：时间单位越短噪声越大 → **日内交易者极少成功**，周线交易者胜率更高
- **多方法互证法则**：基准点止损位 ≈ 头肩颈线止损位 ≈ 长期趋势线时（如 2008/2011），多种独立方法同时触发 → 结论可靠得多

### 13.2 三天法则与基准点（Ch28，p513-533，第 9 版编者按「此章极为重要」）

- **短线顶/底是技术操作的原子单位**——止损位、趋势线、目标值、S/R 全部由它决定
- **三天法则**：疑似低点后，连续 3 个全天价格区间**整体高于低点日的高点** → 确认底部（下跌对称：3 天区间低于高点日的低点 → 确认顶部）
- **基准点** = 确认止损位的参照点：牛市 = 每次短线回调底部（三天逃逸确认后，止损设其下方 6%）；熊市镜像
- **新高基准点**：新高比前高高出 3% → 新高日的最低价成为新基准点（变体 2，止损更紧）
- 回调 40% 规则：趋势前进 15%+ 后回调 ≥ 40%（或不足 40% 但横盘一周以上）→ 再沿趋势方向变动 = 新基准点
- **「止损位只升不降」是不可违背的法则**（除息除权时下移 = 息值，属例外）
- 变体 1（只用波谷）：适合长线、适应高波动；变体 2（波谷+新高）：利润更高，但冲顶段易被震出、常回吐 1/3 利润
- 旗形/三角旗缩量回调中可买，但**找不到基准点的急涨后回调不要贸然操作**（除非①远高于可用的支撑位②处于历史新高区）

### 13.3 量能三位置（Ch28）

天量只应出现在 3 个位置：①形态突破/显著变动日（尤其向上）②长中线趋势创新高/新低日 ③短线趋势结束日（新短线顶/底产生）。
- **其他任何一天出现天量 = 该段趋势可能结束**
- 某短线顶部的量明显大于前期所有短线顶部 → 准备大幅回调（**趋势最后 1-2 次冲顶常伴最大量**）

### 13.4 止损体系（Ch27，p503-513）

**保护性止损 vs 跟进性止损**：
- 保护性（救火）：上一个短线底之下 x%——25 美元级股 5%，低价高波动股 7.5%+（**最保守的高价股也不要小于 5%**）；只升不降
- 跟进性（锁利润）：连涨数日放天量（且非突破新高第 1 天）→ 撤保护性止损，改设当日收盘下方极近处（原文 1/8 美元 ≈ A股 0.5% 内），逃逸上涨中逐日上移；**10 次里 9 次及时平仓是对的**
- 不设紧密止损的唯一例外：**放量创新高且收于高点之上**（涨势未完）
- 通道中点放量 = 预警；再叠加缺口或单日反转 = 双倍警惕

**参数与流派**：
- Kovner：止损设在「股价不容易到达的地方」——locals/自营商会刻意打压到止损密集区震仓
- 欧奈尔 8%；单笔风险 ≤ 资金 2%；ATR 法（初始 2×ATR；吊灯止损 10×ATR ≈ 平均 27% 回撤 = 趋势反转）；海龟 10 日/3 日通道
- 日本谚语：8 次新高卖一半，10 次再卖一半，12 次清仓
- **长线结论：小幅下行就离场 → 长期利润偏低；接受波动 → 高长线利润**（道指 10%-30% 调整后延续原趋势屡见不鲜）
- 经验丰富者可不设止损——编者按：曾让亏损扩大或放跑过整段涨势的人，都不属于「经验丰富」

### 13.5 支撑阻力的应用（Ch30，p548-554）

- 逐波上涨中回调止步前高 = 支撑。**三波规则：沿长线方向第三波上攻后不再买入**（大概率中线调整/整固；下跌同理，连续下跌预计最多三波）
- 突破箱体后：放量突破 + 缩量回调 → 箱体上沿略上方买入；第二波回调买前一高点；之后每波回调买前一波高点——直到第三波后停止
- **支撑失效判断**：按支撑买入后无量阴跌逐波下行 → 必须在某个点决断「支撑已破，小损卖出」；买入时就明确最大可承受损失
- 依长/中线 S/R 买入：找区域**重心**（成交量加权的大致均价位），重心下方设止损
- **三尺度共振**：新高后回调常同时满足 ①回撤涨幅 40-50% ②至基本趋势线 ③至前一短线高点（支撑）——**按最小回调幅度设买入点，按最大回调幅度设止损位**
- 中线调整后买入流程：月/周线定长线 → 日线执行；距支撑 4-5% 时放量 + 单日反转 → 立即买；或开始横盘震荡时买；或距支撑 < 3% 时买
- 获利了结：量价配合前进 → 紧密跟进止损；股价停在 S/R 数日数周后**有效突破反向** → 立即离场
- 期权行权价 = 集中交投区 → 自成 S/R（A股 ETF 期权行权价密集区同效应）

### 13.6 测算目标（Ch32，p558-561）

- **逆趋势方向（回调/反弹）可测**：趋势线/S/R/回撤比例 → 十次对七八次
- **顺趋势方向终点不可测**（狂热/恐慌不遵循规则）→ 用跟进止损，不用固定目标价
- **可测的是最小目标**：

| 形态 | 最小目标 |
|---|---|
| 对称三角 | 形态内第一次回调（回撤段）的幅度 |
| 直角三角 | 长边（第一次回调形成）的幅度 |
| 箱体 | 箱体高度 |
| 头肩 | 头至颈线的垂直距离 |
| 旗形/三角旗 | 旗杆中点规则（旗形后复制旗杆；异常准确） |

- 旗形链：垂直急涨 → 旗形（中点）→ 再复制旗杆 → 第二个整固 + 第三波后**获利了结，让别人接手**；整理形态拖过 3 周不突破 → 卖出（可能是假象）
- **最好的测算参考 = 趋势线 + S/R + 放量**；头肩顶测算 3-4 点而最终跌上百点的案例存在——最小目标只是下界
- 编者按：**永远观察价格到达目标时的具体情况，根据当下决定，不抱死旧目标**

### 13.7 离场 / 建仓信号清单（Ch34，p594-596）

**离场信号**（任一出现，收盘超界 3% 即危险）：
1. 头肩形态不利突破
2. 对称三角形不利突破
3. 箱形不利突破
4. 不利方向的完整短线新低/新高
5. 钻石/楔形不利突破
6. 伴随放量或缺口的单日反转
7. 旗形不利突破
8. S/R 被明显击穿（不利方向）
9. 不利的逃逸缺口
10. 有利走势后出现岛形
11. 无形态支持时基本趋势线被击穿

**建仓信号**（突破需收盘 3% + 量能要求）：
1. 与道氏长线趋势相符（首选条件）
2. 头肩形态突破
3. 对称三角突破（**顶点前最后 1/3 区间内的突破不建**）
4. 直角三角突破
5. 箱体突破（或第 6 次折返的接触点突破）
6. 扩散顶突破（向下）
7. 双/多顶底突破（击穿谷底/谷顶）
8. 楔形突破（或最后 1/3 收缩区内）
9. 充分调整后的旗形（量能证实）
10. 明确 S/R 区内被明确击穿
11. 突破缺口
12. 大走势后的明显岛形
13. 牛市回调触碰/击穿低点趋势线、熊市反弹触碰/击穿高点趋势线（「有利」趋势线）

- **停止上涨 ≠ 卖空机会**：仅破趋势线/短线底部而无完整反转形态 → 只离场，不反向建仓
- **所有仓位建立时必须设止损；只向有利方向移动，绝不反向**

## §14 误区与诚实边界

已从形态篇+战术篇提炼：
1. **「缺口必须回补」是迷信**（§8）
2. **扩散底不存在**——底部喇叭结构按其他形态重新解读（§6）
3. **等差月线上长熊像巨大下降楔形 = 数学假象**，必须半对数（§6）
4. **双顶真形罕见**——间隔 < 1 个月、谷底回调 < 15% 的「双顶」多数是箱体（§5）
5. **单日反转 ≠ 反转**——只表短线动能枯竭（§6）
6. **衰竭缺口 ≠ 反转信号**——只叫停趋势，之后走形态再定方向（§8）
7. **对称三角是最不可靠形态**——假突破最多；但顶点后突破 ≠ 三角突破（§4）
8. **旗形出现在牛市末期**——频出旗形 = 行情接近尾声，不是健康信号（§7）
9. **测量缺口规则用于离场而非入场**（§8）
10. **形态测算目标取 min（测算值，前期涨幅）**——测算不脱离量级常识（§2）
11. **长线趋势线不始于熊市最低点**，而始于其后的中线低点（§11）
12. **不追求底部 10% 与顶部 10%**（巴鲁克）——成功 = 避免大额损失（§12）
13. **机械系统批判**：企图用纯机械方式解决非机械问题（§12）
14. **停止上涨 ≠ 卖空机会**——无完整反转形态不反向建仓（§13.7）
15. **第三波上攻后不买**（§13.5）
16. **顺趋势方向终点不可测，只有最小目标可测**（§13.6）
17. **小幅下行就离场 = 长期利润偏低**——接受波动才能拿住长线利润（§13.4）
18. **技术分析不会自我失效**（Ch35：技术派占比极小，形态由人的行为决定）——但专业资金会故意打穿止损密集区制造假信号 → 对假突破保持警惕（Ch35 + §13.4 Kovner）
