## 0. 总纲：量的地位（先立规矩）

**Murphy 地位声明**（p.129，全书最明确的一句）：
> "价格显然是最重要的因素。交易量和持仓量是次要的，主要作为验证性指标使用。而在这两者之中，交易量又更重要些，持仓量居末位。"

**prism 硬规则**（六源一致，无分歧）：
1. **量永远不出独立买卖信号**，只做"验证 / 否决"——价格给出方向假设，量负责打分
2. **量先价后**（candlestick-framework M4）：买压/卖压的消长先在量上反映，价格反转后验（Murphy p.134-135 同义）
3. 任何量能信号必须看**位置**（E&M 三位置 + 威科夫位置验证）——同一根放量 K 线，在突破日 = 强，在区间中段 = 假，在趋势末端 = 衰竭

## 2. 趋势中的量价验证（规则 #1 展开）

**Murphy 验证规则**（p.132-134）：
- **上升趋势健康**：涨时量重、回时量轻 = 量在验证趋势
- **警告一（背离）**：价格创新高但量比前一峰轻 → 买入压力减轻
- **警告二**：价格回落时量反而变本加厉增加 → 趋势将变故
- **下降趋势健康**：跌时量重、弹时量轻；**此格局破坏才开始找底部信号**（下降趋势中反弹放量 ≠ 底，先当警告二处理）

**威科夫 8 条规则**（§2 模型 3，行为翻译版）：
| 规则 | 上升趋势 | 下降趋势 |
|---|---|---|
| 上坡/下坡量 | 上坡量增价涨 / 下坡量缩价跌 | 上坡量缩反弹弱 / 下坡量增价跌 |
| 三高/三低 | 3H（HH+HL+HC）= 强势 | 3L（LH+LL+LC）= 弱势 |
| 跟随 (FT) | 突破阻力后必须有跟随 | 跌破支撑后必须有跟进 |
| 相对强弱 | 个股强于大盘 = 买盘真实 | 个股弱于大盘 = 供应真实 |
| 枯燥 | 上涨中枯燥 = 再吸筹（健康） | 下跌中枯燥 = 派发中继（危险） |
| 死角 | 高点降+低点升收敛 = 即将突破 | 同左 |

**威科夫关键洞察（反直觉，务必记住）**：
> "很多人认为上涨过程当中成交量递减就判定上涨停止，这种说法是因为不懂成交量行为的内涵。上涨当中成交量减少说明买家的人气开始不足，需求减弱。**但这并不代表市场的压力增加，因为只有市场的供应压力持续增加，才能导致上涨趋势的停止**。"
→ 缩量上涨 = 供应不足 = 健康；**只有"下跌放量"才是停止行为**。单源 B 级但逻辑自洽，与 Murphy 警告二互为镜像（Murphy 说回落放量=变故，威科夫说下跌放量=供应增加，同一件事）。

**E&M 补充**（趋势战术）：旗形/三角旗**缩量回调中可以买入**（量缩证明获利盘不愿卖）；但找不到基准点的急涨后回调不要贸然操作。

## 3. 顶部量能特征（规则 #2 展开）

**四源一致的顶部量能画像**：
1. **道氏**："牛市通常在过度活跃的交易量之中走到它的终点" + 1929.10.5 反弹量能 8 日萎缩 = 价升量缩顶部确认
2. **威科夫**：BC 抢购高潮（天量+加速+上影）→ 二次测试必须**高量**（主力继续出货）→ UTAD 上冲回落 → SOW 放量长阴
3. **E&M 量能三位置 + 冲顶规律**：某短线顶部的量明显大于前期所有短线顶部 → 准备大幅回调；**趋势最后 1-2 次冲顶常伴最大量**；通道中点放量 = 预警，叠加缺口或单日反转 = 双倍警惕
4. **Murphy 胀爆**（p.144-145）：长期上涨后突然急冲 + 巨量（期货再叠持仓下降）→ 顶部突如其来

**顶部量能组合信号**（多源叠加才算确认）：
- 天量/过度活跃（#2）+ 价格不延续（威科夫 EvR：努力无结果）= 停止行为
- 高位滞涨 + 后续反弹缩量（道氏 1929 口径：反弹量能持续萎缩）= 派发完成
- **单看一根天量不构成顶部**——必须等二次测试（威科夫 ST 高量确认 / 道氏"一燕不成夏"）

---

## 4. 底部量能特征（规则 #3 展开）

**四源一致的底部量能画像**：
1. **道氏**："往往在相对较轻的交易量之中拉开序幕"；真正底部 = 成交量曲线走平 + 情绪糟糕透顶
2. **威科夫**：SC 恐慌抛售（天量长阴）→ AR 自然反弹 → **ST 二次测试必须缩量 + 短 K 线**（供应耗尽）；底部必须无量；Spring 急跌急收 + 缩量二次测试 = 最低风险进场
3. **E&M**：头肩底右肩量轻、颈线突破放量；二次测试缩量 = 吸筹完成标志
4. **Murphy 抛售高潮**（p.144-145）：长期下跌后突然急坠 + 巨量 → 随后急剧回升

**底部量能组合信号**：
- 恐慌天量（SC/抛售高潮）只是**第一阶段**，不是买点（威科夫误区 2：看到 SC 就抄底 = 违反左出右进）
- **买点 = 缩量二次测试成功后**（威科夫 ST / E&M 右肩缩量）+ 启动确认（SOS/JOC 放量，威科夫；颈线突破放量，E&M）
- 底部缩量 + 价格不再新低 = 供应枯竭（道氏"成交量曲线走平"+ 威科夫"底部无量"两源一致）

## 5. 突破与形态的量能验证（规则 #4/#6 展开）

**Murphy 形态验证**（p.133-134）：
- 头肩顶：头部量轻 / 跌向颈线量重
- 双顶三顶：后继峰量递轻
- 持续形态（三角/箱体/旗形）：内部量枯竭
- **突破点必须放量才成立**

**E&M 缺口量能表**（§8 缺口）：
| 缺口类型 | 量能 | 判定 |
|---|---|---|
| 普通 | 平常 | 预测意义近零 |
| 突破 | 常放量 | 假突破很少带缺口；缺口后量缩 → 50% 回补；量增 → 短期不回补 |
| 逃逸/测量 | 适中 | 测量规则用于离场而非入场 |
| 衰竭 | 天量但价不延续 | 2-5 天内回补；本身不是反转信号 = 叫停趋势 |

**威科夫死角**：阻力/支撑位 K 线高点降 + 低点升 = 死胡同（量枯竭到极点）= 即将突破（方向由后续 SOS/SOW 定）。

**S/R 强度的量能标准**（E&M §9）：单个深幅天量低点 > 多个均衡量低点——**天量 = 充分换手 = 强记忆价位**。

## 6. 背离体系（规则 #5 展开）

三种背离，按可信度排序：
1. **价格新高 + 量能递轻**（Murphy 警告一 / E&M 头肩顶头部量轻 / 道氏超买上攻乏力）——趋势末段最常见
2. **价格滞涨 + 量能放大**（威科夫 EvR"努力无结果" / E&M 天量但不该出现在这个位置）——供应/需求突变的最早证据
3. **OBV 背离**（Murphy 8.3）：OBV 线方向与价格背离 = 反转警讯，OBV 常先于价格转折。**看 OBV 的趋势不看绝对值**；缺陷：收盘涨跌定正负号，涨 1 分和涨 5% 同权 → A 股用涨幅加权或资金流变通

**背离 ≠ 卖出信号**：背离是"警讯/降权"，配合位置（高位/低位）+ 形态确认（头肩/2B/UTAD）才升级为行动信号。

## 7. E&M 量能三位置（B 级框架，但极好用）

天量只应出现在 3 个位置：
1. 形态突破 / 显著变动日（尤其向上）
2. 长/中线趋势创新高、新低日
3. 短线趋势结束日（新短线顶/底产生）

**其他任何一天出现天量 = 该段趋势可能结束。**

A 股扩展（涨跌停制度下的"天量"变形）：
- 涨停 + 巨量（非一字）= 出货嫌疑（BC 苗头，威科夫 A 股形态库）
- 跌停 + 巨量 = SC 苗头 / 主力接盘
- 一字板无量 = 量价失效区，三位置规则不可用，等开板再看

## 8. 六源分歧与调和

| 分歧点 | 说法 | 调和 |
|---|---|---|
| 威科夫"量是核心" vs Murphy"量是第二位" | 威科夫把量当第一分析要素；Murphy 明确降级 | 不冲突：威科夫的完整单元是"量**价**组合"（努力 vs 结果），从不单看量；Murphy 反对的是**脱离价格的量分析**。prism 取 Murphy 表述作为总纲（量不出独立信号），威科夫作为最细的执行细则 |
| 道氏"顶部过度活跃" vs 威科夫"顶部巨量不涨" | 一个说顶部量极大，一个说顶部量放但价滞 | 同一现象：道氏描述总量水平，威科夫描述量价错位；合并 = 高位 + 天量 + 价格不延续 = 顶部画像 |
| 缩量上涨评价 | 威科夫 = 健康；直觉派 = 见顶 | 威科夫胜出（书中原文论证 + 与 Murphy 警告二镜像自洽）；prism 统一口径：**缩量上涨健康，放量滞涨警告，下跌放量危险** |
