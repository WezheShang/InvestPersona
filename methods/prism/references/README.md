## 模板（首本 = 道氏理论，第二本 = 威科夫）

参考 `dow-theory.md` 和 `wyckoff-method.md` 的结构：
0. 来源与背景（原书 + 验证时长 + 关键史实）
1. 核心基本假设（公理层）
2. N 个核心模型（每个含：定义/规则/应用/局限性/多棱镜关联）
3. 关键术语表（跨语言对照）
4. 经典案例（≥5 个，最好包含中国市场案例）
5. 关键引文（≥15 条）
6. 常见误区（≥15 条，含反直觉）
7. A 股适配（T+1 / 涨跌停 / 量化 / 集合竞价）
8. 多棱镜关联（路由优先级 + 8 段式输出映射）
9. 速查表（决策树 + 事件清单）
