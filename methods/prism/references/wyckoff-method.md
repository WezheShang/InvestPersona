## 0. 来源与背景

| 项 | 内容 |
|---|---|
| 原书 | 《Studies in Tape Reading》, 《Stock Market Technique》 (Richard D. Wyckoff, 1907-1931 著作集) |
| 中文新版 | 孟洪涛《新威科夫操盘法》(珍藏版), 2017 |
| 上游源头 | Richard D. Wyckoff (1873-1934) → 威科夫学生 Bob Evans → 当代 孟洪涛 (Edward Meng, 美国银行/GE Capital 前资管) |
| 验证时长 | 1907 至今 100+ 年市场验证（多市场/多品种/多周期） |
| 关键史实 | 孟 2008 危机前持有 BAC 抄底（巴菲特同期买高盛），从 3 美元涨到 18 美元 |
| 理论核心 | 不是"指标"而是"市场行为翻译"——从量价细节读出主力意图 |

> **威科夫的核心是研究主力机构 (CM) 的行为意图**。
> **市场语言 = 价格 + 成交量 + 走势速度**，背后是供求关系博弈。
> 翻译市场行为 = 把每一根 K 线翻译成"买方/卖方谁在做什么事"。

**与道氏的根本差异**：

| 维度 | 道氏 | 威科夫 |
|---|---|---|
| 视角 | 客观指数运动 (双指数确认) | 主力 (CM) 行为翻译 (单一标的) |
| 粒度 | 月/周/日 | 日/60m/5m 都行 |
| 决策框架 | 三种运动 + 双指数 | 9 步法 (4 阶段吸筹/派发) + 量价确认 |
| 目的 | 定大方向 (牛/熊) | 找最佳进场/离场时机 |

**两者互补**：道氏定大方向，威科夫找具体进场位（多棱镜把它们合成 4 维度并行分析）。

## 1. 核心基本假设（3 条，原书 §1.2 主力资金所遵循的原则）

威科夫理论建立在 **3 条基本公理** 之上。任何一条被推翻，整个框架就要重审。

### 假设 1: 供求关系原则 (Cause-and-Effect 之一)

> "趋势的动力来自供求关系的不平衡。"
> —— 孟洪涛 2017, §1.2

**规则**：
- **供大于求** → 下降趋势
- **求大于供** → 上涨趋势
- **供需平衡** → 震荡区间 (危险区，最容易亏钱)
- 任何技术指标 / 形态 / 几何图形都是供需失衡的**表象**而非本质

**翻译应用**：每一根 K 线都是一个**拍卖结果**。买价 (Bid) 和卖价 (Offer) 之间的博弈 → 谁更急切 → 哪一方赢。

### 假设 2: 因果关系原则 (Cause-and-Effect)

> "趋势形成之前需要准备过程。"
> —— 孟洪涛 2017, §1.2

**规则**：
- **因 = 准备过程** (吸筹震荡 / 派发震荡)
- **果 = 趋势形成** (新趋势)
- 没有看到"因"就不要期待"果"
- **左出右进**：原来趋势秩序没有打破就着急抄底/摸顶 = 违反因果

**经典错误** (书中原话 §1.7)：
> "比如大众交易者喜欢抄底，他们在熊市中的第一个反弹就买入，结果是被套或者被震仓出局。他们失败的原因就是没有等到吸筹过程结束。"

### 假设 3: 努力和结果的关系 (Effort vs Result)

> "成交量的增长没有使价格大幅增长，这是走势停止行为。"
> —— 孟洪涛 2017, §1.2

**规则**：
- **努力 = 成交量** (资金流入流出密度)
- **结果 = 价格的延伸幅度**
- 努力大 + 结果大 = 趋势延续
- 努力大 + 结果小 = **停止行为 (SOT/Spring/UT/UTAD)** = 趋势苗头反转

**经典形态**：
- 阻力区放量滞涨 = 供应战胜需求
- 支撑区放量滞跌 = 需求战胜供应
- 量增 + 价不动 = "努力没结果" = 反转苗头

## 2. 4 大核心模型

### 模型 1: 吸筹 4 阶段 (Accumulation, ACC)

> "主力资金在严格控制价格上涨的前提下，尽可能把市场上所有浮动供应收入囊中，直到按照他们的收购价格，在市场上已经买不到股票。"
> —— 孟洪涛 2017, §2.9 总结

**吸筹 4 阶段框架**：

| 阶段 | 名称 | 核心事件 | 量价特征 | 进场/离场 |
|---|---|---|---|---|
| **阶段 A** | 停止下跌 | PS (初次支撑) → SC (恐慌抛售) → AR (自然反弹) → ST (二次测试) | SC 天量长阴 / 二次测试缩量 | 二次测试成功 (缩量) 后等待 SOS |
| **阶段 B** | 吸筹震荡 | 区间交易 (TR) + 枯燥行情 + 主力暗中吸收 | 区间内高量缩短 / 振幅递减 / 无跟随反弹 | 不进场 (右手边原则) |
| **阶段 C** | 测试 | TSO (终极震仓) 或 Spring (弹簧效应) + 二次测试 | 急速跌破支撑 + 迅速收回 / 缩量二次测试 | **TSO/Spring 后二次测试成功 = 最低风险进场点** |
| **阶段 D** | 启动 | SOS (强势出现) + LPS (最后支撑) 或 JOC (跳离小溪) + LPS | SOS 放量长阳 / JOC 突破阻力 / LPS 缩量回测 | **SOS/JOC 后缩量回测 = 最佳进场点** |

**9 步骤合并表** (从阶段 A 到阶段 D 的 9 个关键事件)：

| 步骤 | 涨势/跌势 | 名称 | 含义 |
|---|---|---|---|
| 1 | 跌 | PS (Preliminary Support) | 初次支撑 - 主力开始试探性买入 |
| 2 | 跌 | SC (Selling Climax) | 恐慌抛售 - 大众交易者崩溃出货 |
| 3 | 跌 | AR (Automatic Rally) | 自然反弹 - 空头平仓推动 |
| 4 | 跌 | ST (Secondary Test) | 二次测试 - 测试供应是否耗尽 |
| 5 | 跌/横 | TR (Trading Range) | 交易区间 - 主力暗中吸筹 |
| 6 | 横/涨 | Spring / TSO | 弹簧效应 / 终极震仓 - 测试浮动供应 |
| 7 | 涨 | ST (Test after Spring) | 二次测试 (Spring 后) |
| 8 | 涨 | SOS (Sign of Strength) | 强势出现 - 需求完全控盘 |
| 9 | 涨 | JOC (Jump Over Creek) + LPS | 跳离小溪 + 最后支撑 |

**吸筹关键判定** (从 §2.7 案例总结)：
- ✅ 底部必须**无量** (供应稀少)
- ✅ 支撑逐渐**抬高** (主力提高收购价)
- ✅ 二次测试必须**缩量 + 短 K 线**
- ✅ 区间内**枯燥** = 主力被动吸筹 (不会主动向上 Bid)
- ✅ 必须有 **SOS 或 JOC 确认**
- ❌ 没有看到任何 SOS/JOC = **不要抄底**

### 模型 2: 派发 4 阶段 (Distribution, DIS)

> "派发区是供应进入市场并逐渐克服需求的过程，派发的结果是终止牛市并最终把市场转为熊市。"
> —— 孟洪涛 2017, 术语表 DIS

**派发 4 阶段框架**（与吸筹镜像）：

| 阶段 | 名称 | 核心事件 | 量价特征 | 离场/做空 |
|---|---|---|---|---|
| **阶段 A** | 牛市停止 | PSY (初次供应) → BC (抢购高潮) → AR (自然回落) → ST (二次测试) | BC 天量长阳 / 二次测试必须**高量** (主力继续出货) | 二次测试确认 (高量) 后做空 |
| **阶段 B** | 派发震荡 | 区间 + 主力暗中出货 | 区间内巨量不涨 / 上影线增多 | 不进场，等待右手边 |
| **阶段 C** | 测试 | UTAD (派发后上冲回落) + 二次测试 | 突破顶部 + 迅速回落 / 缩量二次测试 | **UTAD 后二次测试无力 = 最佳做空点** |
| **阶段 D** | 熊市 | SOW (弱势出现) + LPSY (最后供应释放点) 或 BOI (破冰) + LPSY | SOW 放量长阴 / 破冰后缩量反弹 | **SOW 后缩量反弹 = 做空点** |

**派发关键判定** (从 §3 总结)：
- ✅ 必须出现 **BC (抢购高潮)** = 主力引诱大众接盘
- ✅ 二次测试必须**高量** (确认 BC 是出货而非新上涨)
- ✅ 主力**保护冰线** (派发区底部支撑) 直到出货完成
- ✅ 主力撤掉冰线保护 = **BOI (破冰)** = 派发结束
- ❌ 牛市秩序没被打破之前 = **不要做空** (违反因果)

**做空两策略** (原书后记总结)：
> "顶部做空的策略使用 **SOW/LPSY，破冰**。底部做多的策略使用 **SOS/LPS，JOC/LPS**。"

### 模型 3: 量价行为 8 条规则

> "成交量表示资金流入和流出的密度（交易活动大小），价格只是资金流动的结果。"
> —— 孟洪涛 2017, §1.9

| 规则 | 上升趋势 | 下降趋势 |
|---|---|---|
| **上坡/下坡量** | 上坡量增 + 价涨 / 下坡量缩 + 价跌 | 上坡量缩 + 价反弹弱 / 下坡量增 + 价跌 |
| **三高/三低** | 3H (HH + HL + HC) = 强势 | 3L (LH + LL + LC) = 弱势 |
| **跟进** | 突破阻力后必须有**跟随** (FT) | 跌破支撑后必须有跟进 |
| **相对强弱** | 个股 vs 大盘：个股强于大盘 = 买盘真实 | 个股弱于大盘 = 供应真 |
| **支撑/阻力** | 支撑 = 需求吸收供应 / 阻力 = 供应大于需求 | 供应线突破 = 需求吸收 |
| **超买/超卖** | OB (超买) 角度 > 45° 突然变陡 = 抢购高潮 | OS (超卖) 急速下跌无反弹 = 恐慌抛售 |
| **枯燥/突破** | 上涨趋势中的枯燥 = 再吸筹 (健康) | 下跌趋势中的枯燥 = 派发 (危险) |
| **死角** | 阻力/支撑位 K 线高点降 + 低点升 = 死胡同 (即将突破) | 同左 |

**关键洞察 (原书 §1.9 反复强调)**：
> "很多人认为上涨过程当中成交量递减就判定上涨停止，这种说法是因为不懂成交量行为的内涵。"
> "上涨当中成交量减少说明买家的人气开始不足，需求减弱。但这并不代表市场的压力增加，因为只有市场的供应压力持续增加，才能导致上涨趋势的停止。"

### 模型 4: 主力行为翻译 4 步法 (The 4-Step Reading Process)

> "聪明钱使用的解读市场的三个基本要素：价格、成交量、走势速度。"
> —— 孟洪涛 2017, §1.0 开头

**任何图表的 4 步分析流程** (从 §1.1 主力看盘顺序提炼)：

```
1. 背景 (Context)
   ↓ 确认当前是大趋势中的什么阶段 (吸筹/启动/上涨/顶部/派发/下跌)
2. 价量形态 (Price-Volume Pattern)
   ↓ 观察 K 线长度、成交量高度、变化速度
3. 价量形态的性质 (Interpretation)
   ↓ 强弱评估、原因分析、可能后果
4. 结论和行动 (Action)
   ↓ 进场/离场/收紧止损/等待/观望
```

**5 条分析原则** (原书反复出现，整合)：
1. **大周期优先**：小周期信号必须服从大周期趋势
2. **量价为根**：没有成交量验证的价格形态 = 可疑
3. **因果关系**：没看到"因"不要期待"果"
4. **供求关系**：所有表象都是供需失衡的翻译
5. **停止行为预警**：努力没结果 = 趋势苗头反转

**翻译技巧** (从术语表背后故事提炼)：
- **每一术语都有"背后故事"** —— 这就是多棱镜要的"流派来源"
- 同一形态在不同位置意义不同（如上冲回落 UT 在吸筹区=左手边试探，在派发区=UTAD 顶部确认）
- 同一术语在不同周期意义不同（如 Spring 在日线是大底部信号，在 5m 是短线进场点）

## 4. 经典案例（书中 4 个核心 + 整合 2 个）

### 案例 1: 中国神华 (601088) 2018.7 月线吸筹 (原书 §2.7 案例一)

**背景**：2018.7 A 股熊市，中美贸易战

**价量细节**：
- A→B 段：超卖 + 巨量拦截 (主力首次入场)
- B 后：突破下降趋势线 (供应不足)
- 后续：多次回落 + 缩量 + 高支撑 (高支撑逐步抬高)
- G 附近：量增 SOT (努力没结果 = 供应压力)
- 死角形成后：三高突破 (JOC)
- I 位置：无供应回落 (LPS)

**威科夫判断**：
- 阶段 A 完成：B 是 SC
- 阶段 B 持续：几次测试 + 高支撑
- 阶段 C 完成：终极震仓
- 阶段 D 启动：JOC 后 LPS 进场

**A股适配注解**：A 股 2018.7 之后确实触底反弹，验证了威科夫框架。

### 案例 2: 苹果期货 2018.5 抢购高潮 (原书 §3.1 初始供应案例)

**背景**：2018 上半年苹果期货超级牛市，主力疯狂拉抬

**价量细节**：
- 上涨速度极陡 (接近垂直)
- 巨量 + 上影线
- 出现"垂直供应柱" VSB 顶部

**威科夫判断**：
- 阶段 A 启动：出现 PSY + BC 苗头
- **作者明确警告**："苹果期货后市一直涨到了 9 月末" —— **单凭 BC 就做空违反因果关系** (因果原则 + 左出右进)
- 必须等 ST 二次测试**高量确认** (主力继续出货) + 之后看 UTAD/SOW 才能做空

**A股适配注解**：A 股妖股顶部常出现类似 BC，但 60 日均线常带"金叉"信号，单凭 BC 做空会被反复震仓。

### 案例 3: 深振业 2015.9-2016.2 派发完整周期 (原书 §3.2 弱势出现案例)

**背景**：2015 牛市顶部派发

**9 步完整周期**：
1. PSY (初次供应) - 巨量上影线
2. BC (抢购高潮) - 天量新高
3. AR (自然回落) - 缩量
4. ST (二次测试) - **高量**确认 BC 成立
5. TR 派发震荡 - 主力暗中出货
6. UTAD - 突破顶部后迅速回落
7. ST - 二次测试
8. SOW - 放量长阴
9. BOI - 破冰
10. LPSY - 破冰后缩量反弹 = **最佳做空点**

**结果**：深振业随后腰斩。

**A股适配注解**：这是 2015 年 A 股"杠杆牛"顶部派发典型形态，6-8 月后熔断。

### 案例 4: 美银 BAC 2008-2009 (前言案例)

**背景**：2008 金融危机，BAC 从 50 美元跌至 3 美元

**威科夫时序**：
- 2008.7-9：巴菲特买入 50 亿美元 (PS 初次支撑)
- 2008.9-2009.2：跌至 3 美元 (SC 恐慌抛售)
- BAC CEO 同期大买 (主力接盘)
- 2009.3-10：飙升至 18 美元 (JOC + SOS + LPS 上涨)

**巴菲特**同期买高盛 (123→50→193) 也是相同模式。

**威科夫判断**：标准 4 阶段吸筹 + 阶段 D 启动，验证了"恐慌抛售 + 二次测试成功 = 最佳长线买点"。

### 案例 5: 鄂武商 A 2016.5 + 2017.5 (原书 §2.7 案例二 + 短线底)

**波段底** (2016.5)：
- A→B：超卖 (小型恐慌抛售)
- B 突破供应线 (供应不足)
- C 突破下降供应线
- D 极度缩短的高低范围 + 大成交量 = 需求完全吸收
- E：缩量小幅整理
- F：LPS 进场点

**短线底** (2017.5)：
- 短时间框架内完成吸筹
- 三高跟随 = SOS 启动
- LPS 进场
- 4 个核心信息：需求改变 / 供应稀少 / 轻松上涨 / 停顿无压

### 案例 6: 平安银行 2018 顶部 (原书 §6.14)

**背景**：平安银行 2018.1 顶部后从 14 跌到 7.5

**威科夫时序**：
- H 巨量上涨 (BC 苗头 + 公众冲入)
- I 阻力区巨量消耗需求和供应
- J 主力继续出货 (JOC 失败) = UTAD 顶部确认
- 之后直接 SOW + 持续下跌

**关键警告**：阻力区需要主力资金巨大投入来接盘，但主力此时正在出货，无人接盘 = JOC 失败 = 顶部确认。

## 6. 15 条常见误区（重要反直觉）

### 误区 1: "跌深了就抄底" = 违反因果关系

> ❌ 错误：跌了 50% 觉得便宜就买
> ✅ 正确：必须看到吸筹 4 阶段完整信号 (PS→SC→AR→ST→TR→TSO/Spring→ST→SOS/JOC→LPS)

### 误区 2: "看到 SC 就抄底" = 违反左出右进

> ❌ 错误：恐慌抛售 (SC) 出现就买
> ✅ 正确：SC 后必有 AR，再等 ST (二次测试) **缩量**确认供应耗尽
> 经典例：2015.7 A 股大跌后 7.9 长下影，很多人抄底被套

### 误区 3: "看到 BC 就做空" = 违反因果关系

> ❌ 错误：抢购高潮 (BC) 出现就卖
> ✅ 正确：BC 后必有 AR，再等 ST 二次测试 **高量** (主力继续出货) + UTAD/SOW
> 经典例：2018.5 苹果期货 BC 后涨到 9 月末

### 误区 4: "放量滞涨就要跌" = 50% 误判

> ❌ 错误：看到长上影 + 放量就判断见顶
> ✅ 正确：必须看**位置**（区间内 vs 突破后）+ 跟随（FT）— 派发区高量 = 真实，吸筹区高量 = 吸收
> 经典例：JOC 突破阻力区必须放量（需求吸收供应），不是见顶

### 误区 5: "缩量上涨就见顶" = 100% 误判

> ❌ 错误：上涨中量缩就卖出
> ✅ 正确：上涨中量缩 = 供应不足 = **健康** (维持上涨秩序)；只有**下跌放量**才是停止行为
> 经典例：原书 §1.9 反复强调 —— "上涨当中成交量减少说明买家的人气开始不足……但这并不代表市场的压力增加"

### 误区 6: "上影线就是顶部信号" = 60% 误判

> ❌ 错误：上影线 + 长上影 = 顶部
> ✅ 正确：上影线只是"暂时供应扩大"；要看后续 — 有跟随才确认顶部，无跟随是吸收
> 经典例：原书 §1.7 顶部供应增强案例 — 上影线后 2-4 根 K 线确认才顶部形成

### 误区 7: "跌破支撑就卖" = 错过震仓后大行情

> ❌ 错误：跌破支撑就止损
> ✅ 正确：跌破支撑后立刻看 — 是不是 Spring (跌破后迅速收回)？伴随巨量 + 短 K 线 = 主力接盘
> 经典例：2008.12 美银 BAC 跌到 3 美元 (SC 末期 Spring 区域)

### 误区 8: "突破阻力就追" = 违反因果关系

> ❌ 错误：突破阻力 + 放量就追多
> ✅ 正确：突破后必须等回测 (LPS) + 缩量确认 (无供应)，而不是追突破
> 经典例：JOC 后立刻追经常被 UT (上冲回落) 扫止损

### 误区 9: "单看 K 线不看量" = 100% 错

> ❌ 错误：分析 K 线形态 (头肩顶 / 双底 / 三角)
> ✅ 正确：必须等量价确认 — 同样形态在不同量能下意义完全相反
> 经典例：双底 + 缩量 = 真实见底；双底 + 放量 = 还会再跌

### 误区 10: "震荡区间内抢反弹" = 100% 亏

> ❌ 错误：TR 区间内高抛低吸
> ✅ 正确：TR 区间内主力暗中吸筹/派发，**不要进场**，等右手边 SOS/SOW
> 经典例：原书反复强调"震荡区交易风险最大"

### 误区 11: "用量价信号做短线的量化回测" = 80% 失效

> ❌ 错误：把 SOS/Spring/SOW 当成"形态"做机械化回测
> ✅ 正确：这些是**行为翻译**，必须看**位置** + **背景** + **跟随** 三源确认
> 经典例：Spring 在日线 = 大底部信号，在 5m 图 = 短线进场，性质不同

### 误区 12: "JOC 失败 = 趋势反转" = 90% 误判

> ❌ 错误：JOC 突破后回落 = 顶部
> ✅ 正确：JOC 失败有 3 种情况 — ① 突破后缩量回测（健康）② 突破后放量阴线（失败）③ 上冲回落 UT（扫止损）
> 必须等二次测试/UTAD 才能确认顶部

### 误区 13: "吸筹时间短 = 不充分" = 30% 误判

> ❌ 错误：吸筹必须数月才算数
> ✅ 正确：短线波段底 (3-5 日) 也有完整吸筹 (降低时间框架即可看到)
> 经典例：原书 §2.7 鄂武商短线底案例 — 短时间框架内完成吸筹 4 阶段

### 误区 14: "技术指标叠加威科夫" = 干扰判断

> ❌ 错误：MACD + RSI + KDJ + 威科夫 = 越多越准
> ✅ 正确：原书后记明确 — **"市场的本质行为是一切走势的根本，不需要再去和其他指标结合使用"**
> 经典例：作者亲述花了 15 年才从指标思维过渡到市场行为思维

### 误区 15: "频繁交易" = 90% 亏损

> ❌ 错误：每天都要看盘，每天都要交易
> ✅ 正确：原书后记 — **"频繁交易，着急动手，等于跑步冲向爆仓"**
> 经典例：作者建议 — 用 1 手仓位、1 个策略、1 个周期、1 个方向练习

## 7. A 股适配 (2026-09-05 蒸馏)

### A 股市场结构对威科夫的修正

| 威科夫原版 | A 股现实 | 适配规则 |
|---|---|---|
| T+0 | T+1 | **"次日确认"形态无法立即交易** — Spring 后必须等次日开盘 |
| 无涨跌停 | ±10% / ±20% / ±5% | **一字板/涨停**导致形态失效 (开盘就封板，量价无法表现主力意图) |
| 散户主导 | 70% 散户 + 量化 | 威科夫设计的"主力诱捕散户"模型**仍然有效** (作者本人用 2015 A 股做案例) |
| 持续交易 | 9:30-15:00 | **日线内 4 根 K 线** (60m) = 4 段，**30m 周期**做"超买/超卖"细节更有效 |
| 双指数确认 | 个股 + 板块 + 大盘 | **三层确认**：个股 + 申万行业 + 沪深 300 |

### A 股特殊形态库

1. **T+1 涨停次日**：
   - 涨停 + 缩量 = 一字板 / 主力锁仓
   - 涨停 + 巨量 = 出货嫌疑 (BC 苗头)
   - 跌停 + 缩量 = 主力对倒出货 / 散户恐慌
   - 跌停 + 巨量 = SC 苗头 / 主力接盘

2. **集合竞价** (9:15-9:25)：
   - 高开 + 放量 = PSY 苗头 (主力出货)
   - 低开 + 放量 = PS 苗头 (主力接盘)
   - 平开 + 极小量 = 观望 / 主力等待

3. **A 股典型 9 步案例 (实战)**：
   - **2018.10-2019.1 大盘底部**：PSY (2018.1 BC) → AR → ST → TR → Spring (2018.10.19 破 2449) → ST → SOS (2019.1) → JOC (2019.2) → LPS
   - **2015.6 顶部派发**：PSY → BC → AR → ST (高量) → TR (4 个月震荡) → UTAD (5.28) → ST → SOW (6.15) → BOI (6.26) → LPSY

4. **A 股 60 分钟线适配**：
   - 60m 4 根 = 1 日
   - 60m Spring (跌穿支撑) = 日线级别的初级买入信号
   - 60m JOC + LPS = 中线进场点

5. **量化主导修正** (2020 后)：
   - 程序化触发支撑/阻力 = 传统 Spring/UT 假信号增多
   - 解决：必须等**二次测试 + 量能确认**才能进场
   - 降权：单纯形态信号 (不再单凭 SOS 进场)

### A 股推荐标的池 (适配威科夫的标的特点)

- 适合：日均成交 ≥ 5 亿 / 流通市值 ≥ 100 亿 / 主力持仓明显 (北向 + 公募)
- 不适合：妖股 / 题材股 / 一字板连板 / 仙股 (无主力行为可言)

### 决策树 (右进原则)

```
吸筹阶段 (4 阶段) 检测：
  阶段 A (PS→SC→AR→ST)? → 看 PS/SC/ST 是否齐全
  阶段 B (TR + 枯燥)? → 看区间内振幅递减 + 无跟随反弹
  阶段 C (TSO/Spring + ST)? → 看震仓后二次测试是否缩量
  阶段 D (SOS/JOC + LPS)? → 才是进场点
  
任一阶段缺失 = 不进场 = 违反因果

派发阶段 (镜像) 检测：
  阶段 A (PSY→BC→AR→ST)? → 看 PSY/BC/ST 是否齐全 (二次测试必须高量)
  阶段 B (TR + 巨量不涨)? → 看区间内上影线增多
  阶段 C (UTAD + ST)? → 看上冲回落是否确认
  阶段 D (SOW/BOI + LPSY)? → 才是做空点
  
任一阶段缺失 = 不做空 = 违反因果
```

### 调度优先级

威科夫 (量化维度 D) 在多棱镜路由中的优先级：
- 用户问"主力在做什么" / "吸筹了吗" / "派发了吗" → **★★★★★ 路由到威科夫**
- 用户问"为什么放量不涨" / "为什么缩量不跌" → **★★★★★ 路由到威科夫**
- 用户问"底部在哪" / "顶部在哪" → **★★★★ 配合道氏 + 威科夫 (CREEK/ICE)**
- 用户问"该买还是该卖" → **★★★★ 与所有维度综合** (不单独用威科夫)

### 量价验证规则 (回测时的硬约束)

任何"威科夫信号"进入策略前必须满足：
1. **位置验证**：信号必须在"合理位置" (吸筹区底部 / 派发区顶部 / 趋势中段)
2. **背景验证**：必须看到大周期趋势一致 (主趋势方向 + 吸筹/派发阶段)
3. **量能验证**：必须有量能配合 (Spring 量 / SOS 量 / SOW 量)
4. **跟随验证**：必须有二次确认 (ST / FT)
5. **3 源一致**：形态 + 量能 + 位置 = 至少 2 源一致才输出信号

**避免的伪信号**：
- 区间内任意位置的 Spring (在区间中段 = 假信号)
- 牛市上轨的 SOT (可能是健康缩量，不是见顶)
- 下跌末期的 UT (在派发区 = 真实，在下跌中段 = 假反弹)

- **多棱镜调度**：道氏管维度 A (趋势诊断)，威科夫管维度 D (量价关系) + 维度 C (行为形态库)

**威科夫 vs K线/Nison 的取舍**：
- **共同点**：都看 K 线 + 量
- **差异**：Nison 看形态 (酒田战法 28 种)，威科夫看**主力行为** (25 个对偶术语)
- **多棱镜调度**：K线管形态 (Nison 强势形态)，威科夫管量价 (主力意图)
