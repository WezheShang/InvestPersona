## 1. 核心公理（理念层）

1. **市场 = 资金与筹码的博弈**：场外资金（+买入意愿）vs 场内筹码（+卖出意愿）；博弈的表面是盘口，实际是人心、情绪、欲望和贪念（交易如棋，PAGE 195-196）
2. **情绪推理双引擎**：买入倾向的推理来自赚钱效应，卖出倾向的推理来自亏钱效应——一切短线行为预测都从这两个效应出发
3. **散户就是最大的主力**：不存在万能庄家，合力来自千万散户的趋同行为；解读盘面 = 解读群体行为而非阴谋
4. **情绪有周期，物极必反**：高度板会衰减到极端（无连板）= 新周期起点；情绪极差日之后必有弱转强
5. **只做市场的跟随者**：买入机会，卖出风险，胜率的事情交给概率（PAGE 200）；不做预测顶底的先知
6. **永不止盈永不止损** = 看好买入、不看好卖出；买的是短线趋势，判断与后续走势背离就走——不是死扛，是动态跟踪
7. **交易体系五部分**：理念 → 模式 → 选股 → 仓位 → 回撤控制；缺一即"随心所欲无章法，侥幸盈利最终还给市场"（PAGE 197）

## 2. 核心模型

### 模型 A：情绪周期四段论 `[单源]`

**定义**：短线市场情绪按 **起势 → 发酵 → 疯狂 → 衰退** 循环，循环由赚钱效应/亏钱效应的消长驱动。

| 段 | 情绪特征 | 操作含义 |
|---|---|---|
| 起势 | 赚钱效应初现，首板确立，高度从 2-3 板起步 | 试仓，轻仓打前排 |
| 发酵 | 龙头确立，跟风扩散，板块梯队成形 | 加仓主流，买龙头或龙二 |
| 疯狂 | 高度打满，普涨，人人都赚钱 | 持有不加仓，随时准备撤 |
| 衰退 | 高度断档，亏钱效应扩散，炸板率升高 | 空仓或轻仓，禁打板 |

**规则**：
- 打板只做情绪上升期（起势/发酵）；疯狂段持有不加仓；衰退段禁打板
- 龙头稳则短线情绪稳；龙头崩，坚决不打板
- 衰退期做"弱转强"和低位补涨的确定性低，宁可错过

**局限性**：四段边界靠经验判读，主观性高——工程上用 sentiment-cycle 的 5 段量化版替代（§8.1 映射）。

### 模型 B：高度板周期与新周期信号 `[单源]`

**定义**：用连板最高高度（空间板）刻画周期位置。

**规则链**：
- 龙头打到高度极值（如 9 板）→ 后续周期高度逐级衰减（9 → 8 → 7 → 6 → 3 板…）
- 衰减到**极端：市场无连板（高度=1 板）** = 周期底部 = 新周期起点（物极必反）
- 高度板的存在本身 = 情绪上升期；高度断档 = 衰退确认

**多棱镜关联**：sentiment-cycle 的 max_lb（连板高度）即此模型的数据化；`sentiment_context.py` 输出的高度/晋级率带对比直接消费此规则。

### 模型 C：赢面量化定仓位 `[单源]`

**决策表**（赢面 = 对该笔交易的胜率评估）：

| 赢面 | 仓位 |
|---|---|
| < 60% | 观望（0） |
| 60-70% | 小仓（试错仓） |
| 70-80% | 中仓 |
| 80%+ | 大仓 |
| 90%+ | 满仓（另需三条件，见下） |

**满仓三条件**（同时满足才满仓，一年仅 4-5 次）：
1. 胜率 90%+
2. 上涨空间 30-50%
3. 下跌空间 3-5% 以内

**大盘叠加**：大盘可操作区间 → 总仓位 50-80%；不可操作区间 → 0-30%。

**多棱镜关联**：这是 prism 输出"仓位建议"时的唯一量化依据来源；简版四问（加仓/减仓/建仓/清仓）的仓位档位引用本表。

### 模型 D：三层决策链 + 热点四步 `[单源]`

**三层决策链**：大局定仓位 → 热点情绪定板块 → 板块定个股。
（先判断大盘可操作性决定总仓位，再看哪个板块有赚钱效应，最后在板块内选标的——顺序不可倒置。）

**热点四步**：
1. **预判热点性质**：主流 / 次主流 / 非主流
2. **主流热点**：直接买龙头，或等龙头一字后买龙二（第二波）
3. **次主流热点**：绝佳机会（位置好+逻辑正）可重仓
4. **非主流热点**：轻仓，隔日卖出（不做恋战）

**热点级别判断**（按提出者高度）：顶层设计 > 部门政策 > 大 V 喊话。热点来自题材，持续性来自赚钱效应。

### 模型 E：情绪推理指标组 `[单源]`

盘中/盘前推理市场情绪的三个抓手：
1. **柏拉爱空指标**：前日涨幅前 20 个股的次日表现——衡量赚钱效应的延续性
2. **强势股早盘情绪**：昨日强势股集合竞价与开盘承接
3. **前排个股集合竞价**：看弱转强/抢筹（9:23 后斜率抬升是典型信号）

**多棱镜关联**：工程上已被 sentiment-cycle 的涨停家数/炸板率/晋级率/昨停今负部分替代；集合竞价观察仍是人工盘中项。

### 模型 F：弱转强与极值反转 `[单源]`

**规则**：
- 情绪极差日（涨停 < 15 家，极端 < 10 家）→ 次日"弱转强"高概率，前日涨停品种被资金选中概率高（唯一性稀缺）
- 情绪分歧转一致的节点 = 最佳买点（弱转强/烂板转强/低开高走）
- 极端无连板（模型 B 周期底）→ 新周期启动前夜

**多棱镜关联**：sentiment-cycle 冰点（ice）段的操作含义来源；维度 E 在 ICE 段的规则是"观察弱转强候选，不主动追高"。

### 模型 G：买卖体系 `[单源]`

- **预判买入，确认加仓**：先小仓按预判介入，市场验证判断（发酵）后加仓
- **预判为末，应变为本**：预判只是起点，以盘面实际演变修正操作；走势与判断背离立即纠错卖出
- **卖出理由只有一个**：不再看好（短线趋势破坏），与成本无关、与盈亏无关
- **打板的出发点**：封住涨停享受次日高溢价，不是赌当日几个点

### 模型 H：回撤三条铁律 + 浮盈保护 `[单源]`

1. **能赚 1 块只赚 7 毛**：留 3 毛利润给市场洗世（不追求卖在最高，落袋为王）
2. **决不能把盈利做成亏损**：浮盈回吐到成本线前必须处理（很多个股强势洗盘后新高，但同样多个股跌回成本后一路向下——不赌自己是前者，PAGE 194）
3. **仓位提前计划，知行合一**：仓位在买入前定好，盘中不改剧本

**浮盈止损上移法**：浮盈越大，止损位越贴近现价，保住已有利润。

**复利观**（PAGE 193-194）：目标 = 除去股灾每月 5%（月 5% 滚动 10 年 ≈ 巨额复利；周 2% ≈ 年 280%）；资产增长关键不在某月收益率高低，而在复利 + 控制回撤——**即使不赚钱也要控制风险**；稳定盈利远比不盈利重要。

### 模型 I：龙头/打板标准 `[单源]`

**龙头识别三要素**：
1. 涨停时间靠前（板块内最先封板）
2. 换手率 20-40%（充分换手，人人有筹码才有人气）
3. 历史涨停次数多（股性活跃，有涨停基因）

**标杆结构**：一个周期的标杆 = 中军（大盘核心票，稳定军心）+ 情绪高度股（打开空间的先锋）。

**打板环境闸门**：炸板率接近 50% 的环境，禁止打板（次日溢价为负的亏钱效应）。

**打板的自我修养**：学打板是为了懂情绪，最终反哺低吸（九阳神功/乾坤大挪移之喻——内力（情绪理解）比招式（打板）更重要）。

### 模型 J：复盘体系 `[单源]`

**从大到小三层复盘**：
1. 大盘：涨跌/量能/情绪指标
2. 板块：领涨领跌板块，板块逻辑 → 构成 → 典型个股（对板块内核心票要建立"素养"级熟悉度）
3. 个股：涨停板记忆——**华尔街没有新鲜事，每个板块的活跃分子基本不变**

**每日三记录**（循环统计）：最高连板高度 + 封板率 + 涨停家数。

**多棱镜关联**：sentiment-cycle 的 history.jsonl + zt-daily-log 即此体系的数据化实现，本册提供口径来源。

### 模型 K：机构介入识别 `[单源]`（PAGE 191）

机构也是从券商研报获取逻辑（精力有限无法全行业调研），故：
- **券商研报重点介绍** + 方向逻辑正宗 + 走势趋势很好 + 盘子中等偏上（30-100 亿）+ 基本面支撑 = 可能有机构资金合力参与
- 机构投资是机械的：必须有逻辑支撑，推导严格服从逻辑
- 用途：短线标的叠加机构逻辑 = 持续性加分项（次主流热点"绝佳机会可重仓"的判断依据之一）

### 模型 L：牛市 5 特征 `[单源]`

1. 成交量成倍上涨，资金跑步进场
2. 券商快速上涨是开端
3. 指数持续稳定上涨，均线多头发散
4. 低价股受青睐
5. 牛市在怀疑中前行——所有人确认是牛市时，差不多到头

### 模型 M：心态与纪律（防护罩）`[单源]`

- **90% 时间等待，10% 时间操作**："等"是最重要的交易策略
- **财不入急门**；从每月 5% 小目标做起，不抱一夜暴富美梦
- **三大亏钱原因**：满仓（逆情绪）/ 追涨杀跌 / 逆市场情绪而动
- **亏损后当日禁操作**（团队纪律：防报复性交易）
- 周末/节假日前轻仓或清仓的习惯
- **凡事预则立，不预则废**：不是等到机会来了才做准备（PAGE 193）
- **定力**：清楚自己擅长什么，不一山看着一山高（PAGE 196）
- **下跌日功课**（PAGE 190）：不要发呆埋怨；看哪些抗跌、哪些逆势、逆势逻辑是什么；满仓只剩"等"（胜率随机）；下跌时场内重仓 = 煎熬茫然，轻仓场外 = 机会希望
- **交易如修行**：体系 = 用开仓规则 + 回撤控制规则 + 仓位管理规则把内心肆意挥洒变成机械重复（路径最优原则）；赌看运气随机，交易最终决定的是概率

## 3. 关键术语表

| 术语 | 含义 |

| 赚钱效应 | 持有者赚钱 → 诱发更多买入的传导 |

## 6. 常见误区（15 条，含反直觉）

1. **把打板当目的**——出发点是封住享受次日溢价，不是赌当日几个点
2. **退潮期打板**——炸板率近 50% 环境禁打板（亏钱效应期打板 = 送钱）
3. **满仓逆情绪**——三大亏钱原因之首
4. **亏损后立刻扳本**——盘中割肉追另一只 = 心态已崩；当日禁操作
5. **把"不止损"理解成死扛**——是"不看好才卖"的动态跟踪，不是套牢装死
6. **盈利不走、小损不甘、大损下不了手**——典型把盈利做成亏损的路径（PAGE 194）
7. **追非主流热点还恋战**——非主流默认隔日卖出
8. **迷信庄家控盘**——散户合力才是最大主力，读群体行为不读阴谋
9. **跳过大局直接选股**——顺序：大局定仓位→热点定板块→板块定个股
10. **等机会来了才做准备**——预则立：功课做在机会之前
11. **一山看着一山高**——定力：清楚自己擅长什么模式
12. **不屑月 5%**——复利 + 控回撤 > 单月暴利
13. **下跌日发呆埋怨**——该做功课：哪些抗跌、哪些逆势、逻辑是什么（PAGE 190）
14. **牛市确认才进场**——牛市在怀疑中前行，人人确认时差不多到头
15. **侥幸盈利 = 有能力**——无体系无章法，最终还给市场（PAGE 197）

## 7. A 股适配

| 制度 | 养家规则的耦合点 |
|---|---|
| T+1 | 打板隔日溢价逻辑的制度基础；今日买明日才能卖 → 预判明日情绪是核心功课 |
| 涨跌停 | 高度板周期/炸板率/晋级率全部是涨跌停制度的产物；情绪周期理论在 A 股比成熟市场更有效 |
| 集合竞价 9:15-9:25 | 弱转强/抢筹观察窗（9:23 后斜率） |
| 涨跌停无法盘中止损 | 仓位必须前置控制（模型 C 仓位表的制度原因） |
| 散户占比高 | "散户就是最大的主力"成立的市场基础 |

**与成熟市场理论的差异**：道氏/威科夫/E&M 假设连续交易无涨跌停，情绪周期理论在 A 股是制度增强版——prism 处理 A 股标的时，本册规则优先级高于欧美经典（对短线维度）。

## 8. 多棱镜关联

### 8.1 养家四段 ↔ sentiment-cycle 五段（stages_5）映射

| 养家四段 | stages_5 五段 | 操作规则（维度 E 降权口径） |

## 9. 速查表

### 9.1 每日盘前决策树
```
1. 大局：大盘可操作区间？
   ├─ 可操作 → 总仓位 50-80%；不可操作 → 0-30%
2. 情绪阶段（sentiment_context.py）？
   ├─ ICE    → 观察弱转强候选（前日涨停池），不追高
   ├─ START  → 轻仓试前排首板
   ├─ FERMENT→ 加仓主流，龙头/龙二
   ├─ CLIMAX → 持有不加仓，准备撤
   └─ RETREAT/DIVERGE → 禁打板禁追高（×0.6 / ×0.8）
3. 热点性质？
   ├─ 主流   → 直接买龙头 / 一字后龙二
   ├─ 次主流 → 绝佳机会（位置+逻辑）才重仓
   └─ 非主流 → 轻仓隔日卖
4. 该笔赢面？
   ├─ <60% 观望 / 60-70 小仓 / 70-80 中仓 / 80+ 大仓 / 90+ 满仓(年4-5次)
```

### 9.2 打板检查清单（全部 ✅ 才出手）
- [ ] 情绪上升期（非 RETREAT/DIVERGE）
- [ ] 炸板率 < 45%
- [ ] 涨停时间板块内靠前
- [ ] 换手 20-40%
- [ ] 历史涨停基因活跃
- [ ] 目的 = 次日溢价（不是当日几个点）
- [ ] 仓位符合赢面表，且提前计划

### 9.3 回撤三铁律卡
1. 能赚 1 块只赚 7 毛
2. 决不能把盈利做成亏损（浮盈回吐到成本线前处理）
3. 仓位提前计划，知行合一；浮盈越大止损越上移

### 9.4 事件清单（触发即行动）
| 事件 | 动作 |
|---|---|
| 涨停 < 15 家（极端 <10） | 记录前日涨停池 → 次日盯弱转强 |
| 市场无连板（高度=1） | 周期底：准备新周期启动 |
| 龙头断板/大面 | 全市场短线情绪降档，停止打板 |
| 炸板率逼近 50% | 打板禁手 |
| 当日亏损 | 当日禁再操作 |
| 大涨后心态爆棚"悟道感" | 强制降仓，回到体系检查清单 |
| 周末/节假日前 | 轻仓或清仓习惯 |

### 9.5 一句话总纲
**情绪周期定环境，环境定仓位，仓位定生死；买的是大众情绪，卖的是自己的判断。**
