# prism — 多棱镜：多流派技术分析调度系统

**不是**单一指标工具，也**不是**人物 persona skill——它是把多个流派的技术分析并行跑在同一只标的 / 同一份行情数据上、再交叉验证收敛的**调度系统**。两层架构：

```
prism/
├── SKILL.md          # 调度器：路由规则 / 一致性打分 / 输出模板 / 复权硬规则
└── references/       # 7 本专册（各流派共识方法库，多源交叉蒸馏）
    ├── README.md            # 专册索引
    ├── dow-theory.md        # 道氏理论（趋势判定基座）
    ├── edwards-magee.md     # 《股市趋势技术分析》几何形态
    ├── murphy.md            # 《期货市场技术分析》价位/回撤
    ├── sperandeo.md         # 《专业投机原理》1-2-3 / 2B / 风险控制
    ├── wyckoff-method.md    # 威科夫方法（吸派结构 + 事件库）
    ├── volume-price.md      # 量价分析（六源共识）
    └── yangjia-xinfa.md     # 养家心法（第六柱，情绪周期）
```

## 维度体系

| 维度 | 内容 | 主要专册 |
|---|---|---|
| A 趋势 | 道氏趋势判定 + Sperandeo 1-2-3 / 2B | dow-theory / sperandeo |
| B 价位 | Murphy 回撤 / 百分比 / 关键位 | murphy / sperandeo |
| C 形态 | E&M 几何形态 + 威科夫事件库 | edwards-magee / wyckoff-method |
| D 量价 | 六源共识量价 + 威科夫吸派确认 | volume-price / wyckoff-method |
| E 情绪环境过滤 | 市场级情绪周期作环境闸门，对 A-D 信号降权/禁用（不参与打分） | yangjia-xinfa |

**一致性打分**：A 30% / B 15% / C 30% / D 25%，合计 0~100 —— 75+ 高置信（一句话方向）/ 50~75 中置信（条件性方向）/ <50 低置信（不输出方向，仅观察项）。

**多周期优先级**：周月线 50% / 日线 30% / 60m-30m 15% / 15m-5m 5%；小周期与大周期冲突时标注「信号冲突，大周期压制」并按大周期输出。

## 产线说明（重要）

prism 走的是**书籍蒸馏产线**，与 `personas/` 下的人物 persona 产线（多源调研 → 表达 DNA）不同：

1. 逐本精读原书（部分为 OCR → 人工校对）
2. 跨书交叉蒸馏成专册：同一概念取多源共识，仅单本书支持的内容明确标注 [单源]
3. 调度器把专册按维度编排成可执行判定规则

**为什么不做 persona**：方法论的载体是「规则 + 边界条件」，没有表达 DNA / 决策记录 / 人格要素，persona 模板反而稀释方法。唯一带人物属性的是养家心法——它以第六柱专册形式存在（语录体，全部标 [单源]），另有完整 persona 版在 `../../personas/yangjia/`。

## 数据接入

调度器本身不拉数据，行情由宿主 agent 提供（tushare / tinyshare / akshare / 自备 CSV 均可）。硬规则：

- **必须使用前复权数据**；除权日附近的信号全部标注提示
- 维度 E 依赖外部情绪周期数据（sentiment-cycle 类工具的连板梯队 / 炸板率历史）；**数据不足时自动跳过该维度并标注**，不阻塞其他维度
- 配套脚本（情绪环境读取等）未随仓库分发，由宿主自行实现或跳过

## 输出模式

- **简版（默认）**：一句话结论 + 5 行核心表 + 4 问（加仓 / 减仓 / 建仓 / 清仓）
- **完整版（明示要求时）**：8 段式——现状 → 五维并行分析 → 一致性 → 周期定位 → 量价 → 结论 → 计划 → 免责声明

## Limitations

- 江恩 / 艾略特流派主观性强，权重最低仅作辅助（专册暂缓建设）
- 各专册方法以其来源书籍版本为准，未覆盖书籍之后的新方法
- 蒸馏产物为学习笔记形态，非原书替代品；引用原书内容以原书为准
- 仅供学习研究，**不构成投资建议**
